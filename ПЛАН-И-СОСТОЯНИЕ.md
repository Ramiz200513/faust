## Тема и суть
«Разработка интеллектуального агента для автоматизации многошаговых задач и
удалённого управления персональным компьютером». Телефон (Android, Kotlin) ⇄
релей (Spring Boot + PostgreSQL в Docker) ⇄ агент на ПК (Java 21, UI Automation,
Robot). Своя дообученная модель разбора фраз (Qwen2.5-1.5B + LoRA, Ollama,
`faust-intent`), Gemini (`gemini-3.6-flash`) — для плана и шагов агента.
Ключ Gemini — только в `jarvis-relay/.env`.

Кто что делает: слово «Фауст» — Vosk на телефоне; речь→текст — Android;
текст→команда — релей (фразы навыков → короткие пути → память уроков → своя
модель при уверенности ≥0,9 → Gemini → правила); план и выбор элемента — Gemini;
экран видит UI Automation (или код страницы, или скриншот в Gemini); нажимает —
код агента (Robot).

## Запуск
`C:\diplom\start-faust.bat` или `powershell -File C:\diplom\faust.ps1 start`
(релей + Ollama с пробным запросом и автоперезапуском при зависании + агент).
Перед пересборкой агента (`installDist`) — остановить агента.

## Для защиты: алгоритмы обучения
- Языковая модель: SFT + LoRA (r=16) на Qwen2.5-1.5B, дистилляция знаний из Gemini,
  кросс-энтропия, AdamW, экспорт GGUF q8_0, порог уверенности 0,9.
- Модель «зрения» (план): детектор YOLO, transfer learning, weak supervision
  (авторазметка UIA/DOM), потери CIoU+DFL и BCE, метрики mAP@50/50–95.
- Без нейросетей: память траекторий (case-based), programming by demonstration
  с обобщением переменных, цикл самообучения с воротами качества. Агент — цикл
  рассуждение–действие (ReAct) на Gemini. RL не используется: нет безопасной
  среды для миллионов проб на реальном ПК.

## Правила работы с пользователем
- Отвечать по-русски, комментарии в коде — подробные, по-русски, «почему».
- Сначала замер, потом утверждение; непроверенное перечислять отдельно.
- Не делать навязчивых действий на экране ПК без спроса; живые отправки — только
  в «Избранное» Telegram; APK на телефон — только по просьбе.
- Gemini платный: заранее называть число запросов и цену, ставить потолок.
- Обучение на видеокарте (греется до 86 °C) — только с разрешения.
- Не читать содержимое токенов в `%USERPROFILE%\.jarvis-agent\`.
- Java/Kotlin править через Edit/Write; `faust.ps1` хранить в UTF-8 с BOM.
- Коммитить только по просьбе; новые функции — с переключателями, не ломать рабочее.
