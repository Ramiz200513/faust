# Фауст — агент (Java 21, на ПК)

Программа, которая крутится на управляемом компьютере. Сама подключается к
релею (исходящее соединение — поэтому работает из-за NAT), авторизуется как
`agent` и выполняет команды: простые — напрямую (`Robot`, `ProcessBuilder`),
сложные — ИИ-агентом, который смотрит на окно и решает, что нажать.

Подробное объяснение для защиты — `jarvis/docs/объяснение/4-Агент.md`
и `6-Связки-git-быстрые-команды.md`; полный разбор кода — `ОБЪЯСНЕНИЕ-ПРОЕКТА.md`.

## Требования
- **JDK 21.** На этой машине `JAVA_HOME` указывает на 17, а 21 лежит в
  `%USERPROFILE%\.gradle\jdks\eclipse_adoptium-21-amd64-windows.2` —
  `start-faust.bat` находит её сам.
- Обычный рабочий стол (не headless): Robot, оверлеи и буфер обмена требуют графического сеанса.
- Windows: режим UI Automation работает через помощник на C# (`uia-helper/`,
  готовые файлы лежат в `src/main/resources/uia/` и распаковываются в `~/.jarvis-agent/uia`).

## Запуск
Обычный способ — из корня проекта: `start-faust.bat start` (поднимет релей,
пересоберёт и запустит агента). Вручную:
```
.\gradlew.bat installDist
.\gradlew.bat run --args="ws://127.0.0.1:8080/ws <код привязки>"
```
Код привязки нужен только при первом запуске — дальше используется постоянный
токен из `~/.jarvis-agent/token.properties`. Флаг `--pair-phone` сразу открывает
окно с QR для телефона; то же есть в меню значка в трее.

**Нельзя пересобирать `installDist`, пока агент запущен из `build/install`** —
jar подменится под живой JVM, и агент перестанет разбирать команды. Сначала
`start-faust.bat stop` (или `start`, он перезапустит сам).

Проверки без телефона (агент уже привязан, запросы к ИИ идут через релей):
```
.\gradlew.bat runAskCheck      промпт уточняющих вопросов
.\gradlew.bat runPlanCheck     промпт планировщика
.\gradlew.bat runOverlayDemo   анимации на экране
```
Живые сценарии для таблиц диплома — `com.jarvis.agent.ScenarioRunner <rate|copy|send|unzip> <plan|single>`,
сводная таблица — `scripts\runs-table.ps1`. Они управляют мышью и окнами — запускать, когда ПК свободен.

## Что умеет
- **Простые команды:** открыть сайт/программу/папку (`AppCatalog` читает меню «Пуск»;
  произвольный путь с диска запустить нельзя), скриншот, живой экран, клик/ввод/прокрутка,
  громкость (±2%: клавиши громкости Windows), процессы, блокировка, буфер обмена, файлы.
- **ИИ-задача (`agent_task`)** в трёх режимах зрения: браузер (Selenium/DOM),
  UI Automation (список элементов окна от Windows, 0,3–1,2 с на снимок) и пиксели (скриншот).
- **Многоэтапные задачи:** планировщик (`plan/GeminiTaskPlanner`) делит просьбу на подзадачи
  со своим режимом, `PlanRunner` выполняет их с общей памятью, проверкой результата
  (`ResultVerifier`) и перепланированием хвоста; план подтверждается на телефоне.
- **Вопросы человеку** (`Clarifications`, `PhoneQuestions`): агент спрашивает, а не сдаётся молча;
  молчание = «нет».
- **Файлы:** поиск в Загрузках/Документах/Рабочем столе, вставка файла в чат через буфер,
  распаковка zip (`extract_archive`), слежение за скачиванием.
- **Память:** траектории и готовые планы (`trajectories.json`, `plans.json`) — повтор без модели.
- **Навыки:** рецепт словами с телефона, доверенные скрипты из `~/.jarvis-agent/scripts`,
  показ мышью (`DemoRecorder`, трей «Научить навыку показом…»).
- **Связки:** быстрые и составные фразы, «для каждого из списка» (`lists.txt`), шаг «подожди»,
  «продолжи» с места сбоя (`resume.json`).
- **Git и правки кода** только в репозиториях из `~/.jarvis-agent/repos.txt`: status/pull/commit/push/
  log/branch/discard (`GitTool`, без оболочки), правка кода (`CodeAgent`, `code.engine=auto|claude|gemini`);
  коммит и push всегда с показом диффа и подтверждением на телефоне.
- **Оверлеи:** рамка задачи с кнопкой «Остановить», курсор, «рентген» элементов UIA, панель «План и мысли».

## Безопасность
- Потолок 20 шагов на подзадачу, 3 минуты на одиночную задачу, 10 минут на план (`plan.maxMinutes`);
  одновременно — одна задача.
- Текст страницы и скриншот подаются модели как ДАННЫЕ, а не инструкции (защита от prompt injection).
- `SensitiveInputGuard` блокирует ввод паролей и номеров карт на этапе исполнения.
- `ShellGuard`: терминалы и ввод команд запрещены кодом — вместо них узкие инструменты.
- Окно «Разрешить / Отклонить» перед опасными командами (`confirmSensitiveCommands`, по умолчанию true).
- Каждый запуск пишется в `~/.jarvis-agent/runs/<дата>-<id>.jsonl` — сырьё для таблиц успеха.

## Настройки
`~/.jarvis-agent/agent.properties` читается при каждом обращении — перезапуск не нужен.
Каждый новый режим выключается своей строкой и возвращает прежнее поведение:
`uia.enabled`, `ask.enabled` / `ask.timeoutSec` / `ask.maxPerTask`, `plan.enabled` / `plan.maxMinutes` /
`plan.maxSubtasks` / `plan.maxReplans` / `plan.verify`, `files.enabled`, `code.enabled` / `code.engine`,
`overlay.*` (intro, frame, cursor, widget, xray, plan …).

## Автозапуск
`scripts\install-autostart.ps1` копирует сборку в `%LOCALAPPDATA%\Jarvis\agent` и кладёт ярлык
в автозагрузку. Агент из автозапуска НЕ обновляется пересборкой проекта — после правок
запусти скрипт ещё раз. Токен и привязка в `%USERPROFILE%\.jarvis-agent` скриптом не трогаются.

## Известные ограничения
- Агент работает от имени залогиненного пользователя — не больше его прав (часть модели безопасности).
- Протокол (`protocol/`) — копия Kotlin-протокола из `jarvis/shared`; меняется синхронно в трёх местах.
- Антивирус может реагировать на Robot + запуск процессов.
